## 用户追加的界面范围

用户先要求去掉“设置时长”前置选择、缩小数字框、删除说明小字和 OpenCode 扩展；随后明确取消整轮运行上限。当前两个入口只保留：

- 无消息等待。
- 工具执行时无消息等待。

直接按小时输入，支持小数；数字框宽 56 CSS 像素。去掉来源小字、整轮上限、OpenCode 扩展/专用等待/工具默认执行时长及其说明。继承/管理开关、保存状态和真实错误/不支持状态保留。两处入口仍分别为工作区设置→常规、智能体详情→设置→通用。

新建策略采用通用/工具等待各两小时、整轮不限、OpenCode 跟随通用，避免不可见的十分钟默认值重新收紧预算。编辑已有策略保留未展示的整轮和 OpenCode 字段；没有删除服务端能力、改计时实现或批量清理已有配置。

此界面范围来自本轮直接用户指令，更新了旧任务书对来源小字、整轮上限和 OpenCode 扩展展示的要求；维护者任务书未擅改。后端 R1.1 已通过的 B1 修复不变。
