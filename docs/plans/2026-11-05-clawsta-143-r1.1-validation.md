## 保存契约

原 R1 的整体 JSONB 合并确实会让旧网关残留，也会阻止工作区 PR 设置编辑器删除普通设置键。本次只为 `execution_timeouts` 保留局部更新能力，其余键恢复既有替换语义。服务端在一条 SQL UPDATE 中处理，不依赖新版前端先读取、展开或补发清空字段。

| 请求中的配置容器 | 保存行为 |
| --- | --- |
| 容器省略或为 null | 与原处理一致，保持整个容器 |
| 仅有 `execution_timeouts: <完整策略>` | 替换该策略，保留其他键 |
| 仅有 `execution_timeouts: null` | 删除该策略，保留其他键 |
| 包含其他键，或为空对象 `{}` | 替换所有普通配置键；未提交超时键时保留已存策略，提交时保存或清除它 |

因此，原编辑器的 `{mode:"gateway"}` 清除旧 gateway 和凭据，同时保留超时策略；只保存超时则保持 gateway 和 context_compaction。工作区使用同一规则，PR 目标更新及遗留布尔开关的删除可实际落库。没有修改前端载荷，没有新增请求标志、迁移或通用配置系统。
