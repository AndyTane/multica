# CLI 回调修复（CLAWSTA-136）

Tane 在评估后授权修复。采用已推荐的最小方案：CLI 默认回环、非法回调明确报错、修复私有地址前缀误匹配；不添加可信网段管理功能。

默认回调及监听都使用 `127.0.0.1`，移除根据服务端和出口 IP 推断浏览器位置的逻辑。显式覆盖只接受现有网页支持的私有 IPv4 地址，SSH 沿用端口转发指引与令牌登录。

网页登录入口与 OAuth 返回页对非法或空回调终止 CLI 登录并显示恢复说明，不降级为普通网页登录。OAuth 参数解码错误同样可恢复。校验只匹配完整 IPv4 地址，不接受私有前缀域名、URL 用户信息或片段。

验证覆盖默认/显式回调选择、真实本地 HTTP 监听、SSH 指引、地址校验、网页与 OAuth 拒绝分支，以及已有正常登录测试。无需数据库或权限迁移。发布需服务端和 Client-Kit 同号升级，按项目 OSS 流程交付。
