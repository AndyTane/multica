# 台式机换便携部署包 · 操作单（一屏）

新旧目录默认值：旧部署 `D:\UWorkers\clawsta80\native`，新包解压到 `C:\UWorkers\UWorkers-Portable-v0.2.0`。

## 0. 先确认旧部署目录

双击包里的 `Find-OldDeployment.cmd`，看它列出来的目录：

- 第一行是 `D:\UWorkers\clawsta80\native` → 默认值正确，直接做第 1 步。
- 列出来的是别的目录 → 把第 4 步命令最后的路径换成那个目录。
- 一个都没列出来 → 先别继续，把这个窗口截图发回来。

## 1. 拷到台式机

U 盘把 `UWorkers-Portable-v0.2.0.zip` 拷到台式机的 `C:\UWorkers\`（没有就新建这个文件夹）。**路径越短越好，别放进“桌面/下载”这类很深的目录**。

## 2. 解压

右键 zip →「全部解压缩」→ 目标填 `C:\UWorkers\` → 解压。
得到 `C:\UWorkers\UWorkers-Portable-v0.2.0\`。

## 3. 打开窗口

在解压出来的文件夹里，地址栏输入 `powershell` 回车（或 Shift+右键 →「在此处打开 PowerShell 窗口」）。**不需要管理员**。

## 4. 粘贴这一条命令，按回车

```
cd C:\UWorkers\UWorkers-Portable-v0.2.0 ; .\Setup.cmd -AdoptRoot D:\UWorkers\clawsta80\native
```

（旧目录不是默认值时，只换最后的路径。）

## 5. 等 2~5 分钟，成功会看到

```
U Workers is ready.
  Board (this machine):   https://localhost:13443/
  Board (other machines): https://<台式机局域网IP>:13443/
  ...
```

Windows 若弹「安全警告 · 是否信任此证书」：点**是**（不想点就关掉，不影响服务，只是浏览器会提示一次）。
中途它会先备份旧部署、再停旧服务、再起新版；旧目录和备份都原样保留。

## 6. 到看板检查

浏览器打开它打印的 `https://localhost:13443/` 或局域网地址，用原来的账号密码登录，检查两件事：

1. 原来的看板、任务、成员都还在（数据是旧的，被接管过来了）。
2. 右上角「运行时」里能看到本机，并且有 **Opencode / OpenCode 在线**。

## 7. 失败了怎么办

- **什么都不要删**，旧部署原样保留，备份在 `D:\UWorkers\clawsta80\native\backups\native-*\`（旧目录的 backups 下）。
- 把 PowerShell 窗口里**最后 20 行（尤其红色文字）**截图发回来。
- 如果窗口已经关了，把新包目录下 `logs\` 文件夹里最新的几个文件打包发回来。

## 记三个不要

- 不要删旧目录、不要删 backups。
- 不需要管理员权限、不需要联网。
- 报「安装目录太长/文件未完整复制」时，把 zip 换到更短的目录（如 `C:\UW\`）重新解压再试。
